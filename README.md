# Renal Dose Calculator

เครื่องมือช่วยเภสัชกรผู้ป่วยในปรับขนาดยาตามการทำงานของไต กรอกข้อมูลผู้ป่วยครั้งเดียว เพิ่มยาได้หลายตัว เทียบกับคำสั่งแพทย์ แล้วได้ Pharmacist note รวมอันเดียว

**รอบทดลอง ยังไม่ยืนยัน** ขนาดยาทุกค่ามาจากฉลากยาและแหล่งที่เปิดฟรี ยังไม่ได้ให้เภสัชที่เปิดแหล่งมาตรฐานของโรงพยาบาลตรวจ

ดูตัวอย่าง: เปิด `index.html?example=1`

## ขอบเขตรอบแรก

- ยา: ceftriaxone, cefazolin, ceftazidime, acyclovir ฉีดและกิน, amoxicillin-clavulanate ฉีดและกิน
- ผู้ป่วยอายุ 18 ปีขึ้นไป ไม่ฟอกไต ฟอกเลือด (HD) ล้างไตทางช่องท้อง (CAPD APD)
- ไม่อยู่ในรอบนี้: การให้ยาทางน้ำยาล้างไต CRRT เด็ก eGFR

## หลักของเครื่องมือ

ช่วยไกด์ ไม่ตัดสินแทน ไม่บังคับ แต่เตือน: จอเสนอขนาดตามแหล่งพร้อมที่มา เภสัชแก้ได้ จุดที่แหล่งขัดกันหรือค่าไตตกขอบ ขึ้นทุกทางให้เลือกและติดป้าย "แนะนำ" ที่ทางเดียว ขนาดที่หลุดขึ้นป้ายเตือน (แดง เกินขนาดสูงสุด, เหลือง สูงกว่าที่แนะนำ, ฟ้า ต่ำกว่าที่แนะนำ) แต่ไม่ห้ามกดต่อ เรื่องที่ไม่มีข้อมูลบอกตรงๆ ว่ายังไม่รองรับ

## ที่มา

- กติกาเต็มอยู่ในสเปก `../01-สเปกกติกาคำนวณ.md` (พี่เคาะครบ 2026-11-08) ที่มาแต่ละค่าอยู่ในตารางรวมแหล่ง `../2026-11-08-ตารางรวมแหล่ง-ปรับยาไต-ฟอกไต-5ยา.md`
- ลำดับแหล่งเมื่อขัดกัน: ฉลากทางการของรูปแบบยาที่ใช้ (DailyMed สหรัฐ, emc อังกฤษ) แล้วแนวทางวิชาชีพ (IDSA 2009) แล้วตารางโรงพยาบาลมหาวิทยาลัย (Hamilton 2016, Stanford 2026)
- CrCl ใช้ Cockcroft-Gault น้ำหนักตามกลุ่ม BMI (Winter 2012 ผ่าน MDCalc) ไม่ปัด SCr พื้นที่ผิวกายใช้ Mosteller
- ข้อมูลยาและกติกาอยู่ใน `index.html` ระหว่าง `DATA-START` กับ `DATA-END` ตัวคำนวณอยู่ระหว่าง `CALC-START` กับ `CALC-END`

## ทดสอบ

```
node tests/test-calc.mjs             # ชุดทดสอบตัวคำนวณ ตัวอย่างในสเปก ขอบช่วงทุกแบบ บั๊กที่เคยเจอ และ note
python3 -I tests/fuzz.py 100000      # สุ่มเทียบกับตัวคำนวณแยก tests/reference.py (Decimal 60 หลัก วิธีจัดแถวต่างกัน)
node tests/e2e-ui.mjs 300            # กดหน้าเว็บจริงใน Chrome เทียบผลบนจอกับตัวคำนวณ ตรวจล้นจอ 300 ถึง 1280 px ภาพจออยู่ tmp/shots/
node tests/probe-ui.mjs              # ตรวจการใช้งาน ปุ่มเล็ก ตัวหนังสือเล็ก ช่องไม่มีป้าย ลำดับหัวข้อ ความต่างสี
node tests/make-hand-check.mjs       # สร้าง docs/ตารางตรวจมือ-การคำนวณ.md ไว้กดเครื่องคิดเลขตาม
```

## คู่มือ

คู่มือการใช้อยู่ `manual/` (ลิงก์ "คู่มือการใช้" ท้ายเครื่องมือ) แก้หน้าตาเครื่องมือหรือกติกาแล้วถ่ายรูปและสร้าง PDF ใหม่

```
node tests/make-manual-shots.mjs     # ถ่ายรูปจอมือถือ 390 px ลง manual/img/
node tests/make-manual-pdf.mjs       # สร้าง manual/renal-dose-calculator-manual.pdf ขนาด A4
```
