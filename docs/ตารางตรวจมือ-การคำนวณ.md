# ตารางตรวจมือ การคำนวณ Renal Dose Calculator

> สร้างด้วย `node tests/make-hand-check.mjs` ตัวเลขมาจากตัวคำนวณในหน้าเว็บ ไว้ให้เภสัชกดเครื่องคิดเลขตามทีละขั้น ถ้าได้ไม่ตรงแม้ตัวเดียว แจ้งบรร
> ปัดทศนิยม 1 ตำแหน่งแบบครึ่งขึ้น ค่าที่ปัดแล้วคือค่าที่ใช้จัดแถว ไม่ปัด SCr

## 1 ชาย 72 ปี ไม่ฟอก (คน A ในสเปก)

ข้อมูล: ชาย อายุ 72 ปี น้ำหนัก 55 kg ส่วนสูง 160 cm SCr 2.1 mg/dL

| ขั้น | กดเครื่องคิดเลข | ได้ |
|---|---|---|
| ส่วนสูงเป็นนิ้ว | 160 / 2.54 | 62.9921 |
| IBW | 50 + 2.3 x (62.9921 - 60) | 56.8819 |
| AdjBW | 56.8819 + 0.4 x (55 - 56.8819) | 56.1291 |
| BMI | 55 / (1.60 x 1.60) ปัด 1 ตำแหน่ง | 21.5 |
| น้ำหนักในสูตร | BMI 21.5 18.5 ถึงน้อยกว่า 25 ใช้ IBW | IBW 56.8819 |
| CrCl | (140 - 72) x 56.8819 / (72 x 2.1) | 25.5818 ปัดเป็น **25.6** |
| พื้นที่ผิวกาย (Mosteller) | รากที่สองของ (160 x 55 / 3600) | 1.5635 |
| CrCl ต่อ 1.73 ตร.ม. (acyclovir) | 25.5818 x 1.73 / 1.5635 | 28.3066 ปัดเป็น **28.3** |

**Cefazolin** ขนาดปกติ 1000 mg ทุก 8 ชม. แพทย์สั่ง 1000 mg ทุก 8 ชม.

- CrCl 25.6 อยู่แถว 11-34 ครึ่งขนาดปกติ 1000 / 2 = 500 mg ทุก 12 ชม.
- ผล: Cefazolin 500 mg IV q 12 hr | ขนาดสูงกว่าที่แนะนำตามการทำงานของไต

## 2 หญิง 80 ปี ตัวเล็ก ไม่ฟอก (คน B)

ข้อมูล: หญิง อายุ 80 ปี น้ำหนัก 42 kg ส่วนสูง 148 cm SCr 0.6 mg/dL

| ขั้น | กดเครื่องคิดเลข | ได้ |
|---|---|---|
| ส่วนสูงเป็นนิ้ว | 148 / 2.54 | 58.2677 |
| IBW | 45.5 + 2.3 x (58.2677 - 60) | 41.5157 |
| AdjBW | 41.5157 + 0.4 x (42 - 41.5157) | 41.7094 |
| BMI | 42 / (1.48 x 1.48) ปัด 1 ตำแหน่ง | 19.2 |
| น้ำหนักในสูตร | BMI 19.2 18.5 ถึงน้อยกว่า 25 ใช้ IBW | IBW 41.5157 |
| CrCl | (140 - 80) x 41.5157 / (72 x 0.6) x 0.85 | 49.0116 ปัดเป็น **49.0** |
| พื้นที่ผิวกาย (Mosteller) | รากที่สองของ (148 x 42 / 3600) | 1.3140 |
| CrCl ต่อ 1.73 ตร.ม. (acyclovir) | 49.0116 x 1.73 / 1.3140 | 64.5270 ปัดเป็น **64.5** |

**Acyclovir** ขนาดปกติ 10 mg/kg ทุก 8 ชม. แพทย์สั่ง 400 mg ทุก 8 ชม.

- ค่าไตที่ใช้แบ่งแถว: CrCl ต่อ 1.73 ตร.ม. = 64.5 (แนะนำ) / CrCl = 49.0 mL/min ไม่แปลง ใช้ "CrCl ต่อ 1.73 ตร.ม. = 64.5"
- ต่อ 1.73 ตร.ม. 64.5 อยู่แถว มากกว่า 50 ขนาดเต็ม 10 x 42 = 420 ปัดทีละ 50 = 400 mg ทุก 8 ชม. (ถ้าเลือก CrCl ไม่แปลง 49.0 อยู่แถว 25-50 เป็นทุก 12 ชม.)
- ผล: Acyclovir 400 mg IV q 8 hr | ขนาดเหมาะกับการทำงานของไตแล้ว

## 3 ชาย 50 ปี อ้วน ไม่ฟอก (คน C)

ข้อมูล: ชาย อายุ 50 ปี น้ำหนัก 110 kg ส่วนสูง 170 cm SCr 1.8 mg/dL

| ขั้น | กดเครื่องคิดเลข | ได้ |
|---|---|---|
| ส่วนสูงเป็นนิ้ว | 170 / 2.54 | 66.9291 |
| IBW | 50 + 2.3 x (66.9291 - 60) | 65.9370 |
| AdjBW | 65.9370 + 0.4 x (110 - 65.9370) | 83.5622 |
| BMI | 110 / (1.70 x 1.70) ปัด 1 ตำแหน่ง | 38.1 |
| น้ำหนักในสูตร | BMI 38.1 25 ขึ้นไป ใช้ AdjBW | AdjBW 83.5622 |
| CrCl | (140 - 50) x 83.5622 / (72 x 1.8) | 58.0293 ปัดเป็น **58.0** |
| พื้นที่ผิวกาย (Mosteller) | รากที่สองของ (170 x 110 / 3600) | 2.2791 |
| CrCl ต่อ 1.73 ตร.ม. (acyclovir) | 58.0293 x 1.73 / 2.2791 | 44.0478 ปัดเป็น **44.0** |

**Acyclovir** ขนาดปกติ 10 mg/kg ทุก 8 ชม. แพทย์สั่ง 850 mg ทุก 8 ชม.

- น้ำหนักคิดขนาด (BMI 30 ขึ้นไป): AdjBW 83.6 kg (แนะนำ) / IBW 65.9 kg ใช้ "AdjBW 83.6 kg"
- ค่าไตที่ใช้แบ่งแถว: CrCl ต่อ 1.73 ตร.ม. = 44.0 (แนะนำ) / CrCl = 58.0 mL/min ไม่แปลง ใช้ "CrCl ต่อ 1.73 ตร.ม. = 44.0"
- น้ำหนักคิดขนาด AdjBW 83.5622 x 10 = 835.6 ปัดทีละ 50 = 850 mg ต่อ 1.73 ตร.ม. 44.0 อยู่แถว 25-50 ทุก 12 ชม.
- ผล: Acyclovir 850 mg IV q 12 hr | ขนาดสูงกว่าที่แนะนำตามการทำงานของไต

## 5 ชาย 60 ปี ฟอกเลือด น้ำหนักหลังฟอก 58 kg

ข้อมูล: ชาย อายุ 60 ปี น้ำหนัก 58 kg ส่วนสูง 165 cm HD

| ขั้น | กดเครื่องคิดเลข | ได้ |
|---|---|---|
| ส่วนสูงเป็นนิ้ว | 165 / 2.54 | 64.9606 |
| IBW | 50 + 2.3 x (64.9606 - 60) | 61.4094 |
| AdjBW | 61.4094 + 0.4 x (58 - 61.4094) | 60.0457 |
| BMI | 58 / (1.65 x 1.65) ปัด 1 ตำแหน่ง | 21.3 |
| น้ำหนักในสูตร | BMI 21.3 18.5 ถึงน้อยกว่า 25 ใช้ IBW | IBW 61.4094 |

**Cefazolin** ขนาดปกติ 1000 mg ทุก 8 ชม. แพทย์สั่ง 1000 mg ทุก 8 ชม.

- ขนาดในผู้ป่วยฟอกเลือด: 20 mg/kg หลังฟอกเสร็จทุกครั้ง = 1,250 mg (แนะนำ) / ขนาดคงที่หลังฟอกเสร็จทุกครั้ง = 1,000 mg ใช้ "20 mg/kg หลังฟอกเสร็จทุกครั้ง = 1,250 mg"
- 20 mg/kg x 58 = 1,160 mg ปัดทีละ 250 (1,160 / 250 = 4.64 ปัดเป็น 5) = 1,250 mg หลังฟอกเสร็จทุกครั้ง
- ผล: Cefazolin 1,250 mg IV หลังฟอกเลือดเสร็จทุกครั้ง | ควรปรับขนาดสำหรับผู้ป่วยฟอกเลือด
